Uzair Ahmed - Resume Website

Files:
- index.html: website content and sections
- style.css: page design and responsive layout
- script.js: theme button and current year

How to view:
1. Extract this ZIP file.
2. Open the resume_website folder.
3. Double-click index.html to open it in a browser.

Interactive feature:
Use the Dark mode button in the top navigation to switch between light and dark themes.

Publishing:
Create a GitHub repository, upload these files, then enable GitHub Pages from the repository's Settings > Pages.
The GitHub repository URL and live website URL must be added after publishing.
